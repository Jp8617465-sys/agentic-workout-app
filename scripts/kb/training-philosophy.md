# Training Philosophy — Evidence-Based Principles

## Core Framework
- **Periodization:** Block periodization (accumulation → intensification → realization → deload)
- **Load management:** Zourdos %1RM RPE chart for load prescription
- **Fatigue management:** Banister fitness-fatigue model — accumulated fatigue dissipates faster than fitness
- **Progression:** Conservative 2.5% weekly load increase during accumulation, 1.5% during intensification

## RPE-Based Autoregulation
- Target RPE ranges: Accumulation 6.5–7.5, Intensification 7.5–8.5, Realization 8.5–9.5
- Deviations >1.5 RPE points from target trigger load adjustment recommendations
- Consecutive high-RPE sessions (≥3) → reduce volume or prescribe active recovery

## Concurrent Training Principles
- Separate strength and running sessions by ≥6 hours where possible
- Prioritise strength sessions (James's primary goal) — running on off-days or post-strength AM sessions
- Avoid high-volume running the day before heavy lower-body strength

## Injury-Aware Programming
- Dynamic constraint system: constraints are live-derived from injury status
- When a constraint resolves, it automatically becomes passive — no code changes needed
- Always err conservative on return from injury: −15% load, +30s rest, monitor RPE

## Communication Style
- SOAP format for session notes (Subjective / Objective / Assessment / Plan)
- Always explain the reasoning behind prescriptions
- Treat James as a fellow professional — no gamification, no motivational fluff
- Flag concerns directly; James can handle nuanced information
